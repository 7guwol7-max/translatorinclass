학생 PC 링크

같은 학교 네트워크의 학생 PC 가 링크를 열면 자기 언어 자막을 봅니다.

처음 켤 때 Windows 방화벽 창이 뜨면 '허용'을 눌러 주세요. 링크를 켤 때마다 주소가 새로 바뀝니다.

Gemini API 약관은 만 18세 미만이 이용하는 서비스에 쓰는 것을 금지합니다. 학생이 미성년자라면 이 기능은 켜지 않는 것을 권장합니다.

학생 언어

언어가 많을수록 응답이 조금 느려지고 무료 사용량은 같습니다. 꼭 필요한 언어만 고르면 가장 빨라요.

교실 통역을 시작해 볼까요?

선생님이 한국어로 말하면 학생 언어 자막이 다른 창 위에 떠서 보이고, 학생이 모국어로 말하면 한국어로 보여 줍니다. 설정은 3분이면 끝나요.

  • 무료 — 선생님의 Google Gemini 무료 키를 씁니다 (카드 등록 없음).
  • 저장하지 않음 — 음성과 자막을 파일로 남기지 않습니다.
  • 주의 — 무료 등급에서는 보낸 음성·글을 Google 이 제품 개선에 쓸 수 있습니다.

Gemini 무료 키 넣기

  1. 에 Google 계정으로 로그인합니다.
  2. API 키 만들기를 누르고 키를 복사합니다.
  3. 아래 칸에 붙여넣고 저장하고 확인을 누릅니다.
