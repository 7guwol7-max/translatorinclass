# 교실 통역 사용 안내 (교사용)

> 📘 화면 그림이 있는 **사용설명서(PDF)**: [ClassroomInterpreter-Manual-ko.pdf](https://github.com/7guwol7-max/translatorinclass/releases/latest/download/ClassroomInterpreter-Manual-ko.pdf) — 설치부터 첫 수업까지 따라 하기. 프로그램 왼쪽 메뉴 아래 **사용설명서 (PDF)** 로도 열 수 있습니다.

교사 PC(Windows)에서 쓰는 실시간 통역 자막 프로그램입니다.
선생님이 한국어로 말하면 학생 언어 자막이 **다른 창 위에 떠서** 보이고,
학생이 모국어로 말하면 언어를 자동으로 알아듣고 한국어로 보여줍니다.

- 기본: **Gemini 무료 등급 + 선생님 본인 키** → 0원
- 선택: 번역만 **Claude**(유료, 선생님 본인 키)
- 선택: 학생 PC 에서 자기 언어 자막을 보는 **링크**
- 선택: 학급 언어의 번역 데이터를 찾아보는 **AI 허브 데이터** (선생님 본인 AI 허브 키)

---

## 1. 설치
GitHub 계정 없이 누구나 내려받을 수 있습니다. 둘 중 하나를 고르세요.
- **설치판**: [ClassroomInterpreter-Setup.exe](https://github.com/7guwol7-max/translatorinclass/releases/latest/download/ClassroomInterpreter-Setup.exe) → 실행해서 설치 (관리자 권한 없이 선생님 계정에만 설치) → 바탕화면 **교실 통역** 아이콘
- **설치 없는 판**: [ClassroomInterpreter-Portable-win-x64.zip](https://github.com/7guwol7-max/translatorinclass/releases/latest/download/ClassroomInterpreter-Portable-win-x64.zip) → 원하는 폴더에 압축 풀기 → `ClassroomInterpreter.exe` 실행

코드 서명이 없어 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
이전 버전과 변경 내용은 [릴리스 페이지](https://github.com/7guwol7-max/translatorinclass/releases/latest)에서 볼 수 있습니다.

## 2. 처음 설정 (약 3분)
처음 실행하면 **처음 설정** 창이 뜹니다. 순서대로 따라 하면 됩니다. (나중에 왼쪽 아래 **처음 설정 다시 하기**로 다시 열 수 있어요)
1. **시작**: 프로그램이 하는 일과 개인정보 안내를 읽고 **학생·보호자 동의** 칸에 표시합니다.
2. **Gemini 키**: [Google AI Studio](https://aistudio.google.com/apikey) 에 Google 계정으로 로그인 → **API 키 만들기** → 키를 복사해 붙여넣고 **저장하고 확인** (카드 등록 불필요)
   - 연결되면 이 키로 쓸 수 있는 모델 여러 개를 **자동으로 묶어** 씁니다. 무료 한도를 따로 적을 필요가 없습니다.
3. **학생 언어**: 학급 학생들의 언어를 고릅니다.
4. **마이크**: 마이크를 고르고 말해 보면 막대가 움직입니다.
5. **완료** → 수업 화면의 큰 버튼을 누르면 시작합니다.

> 키는 이 PC 의 Windows 암호화 저장소(DPAPI)에 저장되고, 화면에는 `AIza…abcd` 처럼 가려서만 보입니다.
> 키를 다른 선생님과 같이 쓰지 마세요 (무료 한도가 같이 줄어듭니다).

## 3. 수업 준비 (왼쪽 메뉴)
- **학생 언어**: 학급 학생들의 언어를 눌러 고릅니다. 자막 창에는 최대 3개 언어까지 보입니다.
- **마이크**
  - 마이크가 하나면: **"교사·학생이 이 마이크를 같이 씀(자동 구분)"** — 한국어면 선생님, 다른 언어면 학생으로 처리
  - 선생님 무선 마이크 + 학생용 마이크 두 개면: 교사 마이크는 **"교사 전용"**, 학생 마이크를 따로 지정
- **용어집**: `광합성 = photosynthesis = quang hợp` 처럼 한 줄에 하나씩
- **속도·무료 사용량 → 자막 속도**
  | 속도 | 자막이 나오는 때 | 무료 사용량 |
  | --- | --- | --- |
  | **빠르게** (기본) | 말이 끝나고 보통 2~5초 | 짧게 끊어 자주 보내므로 가장 많이 씀 |
  | 보통 | 2~3초 더 늦음 | 짧은 말을 모아 보냄 |
  | 절약 | 5~10초 더 늦음 | 길게 묶어 약 4분의 1만 씀 |

  오늘 남은 무료 사용량이 20% 아래로 내려가면 자동으로 '절약'이 됩니다.
- **속도·무료 사용량 → 번역**: 기본은 **빠르고 넉넉하게**(Flash-Lite 먼저). 번역이 어색하면 **더 자연스러운 번역**(Flash 먼저)을 고르세요.
- 말이 문장 중간에서 끊기면 먼저 그 부분만 번역해 보여주고, 이어지는 말이 오면 **문장 전체를 다시 번역해 같은 자리의 자막을 바꿉니다** (요청 수는 늘지 않음).

## 4. 자막 창 옮기기
- **자막 창** 메뉴
  - **어느 화면에?**: 프로젝터·TV 가 연결돼 있으면 화면을 고릅니다 (Windows 디스플레이 설정이 **확장**일 때). 화면 이름 끝의 `150%` 같은 숫자는 Windows 배율이며, 노트북과 프로젝터의 배율이 달라도 정확한 자리로 갑니다.
  - 화면을 따로 고르지 않았으면 자막 창은 프로젝터 화면에 뜨고, 프로그램을 켠 뒤에 프로젝터를 꽂아도 그쪽으로 옮겨 갑니다.
  - **어디에?**: 모니터 그림의 9칸 중 하나를 누르면 자막 창이 그 자리로 바로 옮겨집니다.
  - **크기**: 너비·높이·글자 크기를 밀대로 바꿉니다.
- **마우스로 바로 옮기기**: 자막 위에 마우스를 올리면 오른쪽 위에 **도구 막대**가 나타납니다.
  - 보라색 **이동** 버튼을 누른 채 끌면 옮겨집니다.
  - 오른쪽 아래 모서리를 끌면 크기가 바뀝니다.
  - **멈춤**: 쉬는 시간·개인적인 이야기를 할 때 듣기를 잠시 멈춥니다 (다시 누르면 시작)
  - **A− / A+** 로 글자 크기, 눈 모양 버튼으로 숨기기
  - 도구 막대가 없는 곳은 클릭이 아래 창(PPT 등)으로 그대로 전달됩니다.
- 숨긴 자막은 **수업** 화면의 **자막 보이기** 또는 `Ctrl`+`Alt`+`H` 로 다시 띄웁니다.

## 5. 수업 중
| 할 일 | 방법 |
| --- | --- |
| 듣기 시작/멈춤 | 수업 화면의 **큰 버튼**, 위쪽 **수업 시작** 버튼, 자막 창의 **멈춤**, 또는 `Ctrl`+`Alt`+`P` |
| 자막 숨기기/보이기 | `Ctrl`+`Alt`+`H` |
| 자막 전체를 끌어서 옮기기 | `Ctrl`+`Alt`+`M` → 끌어서 옮기고 가장자리로 크기 조절 → 다시 `Ctrl`+`Alt`+`M` |

- 자막은 받는 대로 바로 채워지고(끝에 깜빡이는 점), 다 받으면 확정됩니다. 20초 동안 말이 없으면 자막이 잠시 사라집니다.
- 위쪽의 **자막이 말 끝나고 약 N초 뒤 나와요** 가 지금 자막 지연입니다.
- 위쪽 오른쪽 **오늘 남은 무료 사용**은 지금 속도로 수업을 얼마나 더 할 수 있는지입니다. 누르면 모델별 사용량이 나옵니다.
  한도는 **매일 오후 4~5시(한국 시간)** 에 다시 채워집니다.

## 5-1. 무료 Gemini 키의 한계와 프로그램이 하는 일
| 무료 키에서 생기는 일 | 프로그램이 하는 일 | 선생님이 할 수 있는 일 |
| --- | --- | --- |
| 응답이 들쭉날쭉함 (같은 모델도 1~13초) | 모델 여러 개 중 **지금 가장 빠른 것**을 골라 씀. 2~5초 안에 답이 없으면 **다른 모델에 한 번 더** 물어 먼저 온 답을 씀 | 학생 언어를 꼭 필요한 것만 고르기 |
| 분당·하루 요청 한도 | 한도는 **모델마다 따로**라서, 한 모델이 막히면 다른 모델로 바로 이어감. Google 이 알려 주는 실제 한도를 배워 남은 시간을 계산 | 오래 쓰는 날은 **보통** 또는 **절약** 속도 |
| 서버 오류·멈춤 (가끔 30초 넘게 답이 없음) | 10초 넘게 아무것도 안 오면 끊고 다른 모델로 넘김 | — |
| 모델이 없어지거나 바뀜 | 이 키로 못 쓰는 모델은 자동으로 빼고 7일 뒤 다시 확인 | — |
| 보낸 음성·글이 Google 제품 개선에 쓰일 수 있음 | 음성·자막을 파일로 남기지 않음 | 동의 받기, 개인적인 이야기는 **멈춤** |
| 하루 한도가 오후 4~5시에 채워짐 | 남은 시간을 보여 줌 | 오전 수업이 많은 날은 전날 오후 4시 이후 사용을 줄이기 |

## 5-2. Live 모드 (시험 중)
말을 쉼에서 끊어 보내는 대신, **말하는 동안 소리를 Gemini Live 로 흘려 보내** 말하는 중에도 번역이 나오게 하는 방식입니다. 기본은 꺼져 있습니다.
1. **API 키 → Gemini 연결 테스트** 를 한 번 눌러 이 키로 쓸 수 있는 Live 모델 목록을 받습니다.
2. **속도·무료 사용량 → Live 모드** 에서 **Live 연결 테스트** 를 누릅니다. "Live 연결 성공"이 나오면 쓸 수 있습니다.
3. **말하는 동안 바로 번역하기** 를 켜고 수업을 시작합니다. 수업 화면 위쪽에 **Live · 자막이 말 끝나고 약 N초** 가 나오면 Live 로 자막을 만드는 중입니다.

- 학생 언어마다 연결을 하나씩 엽니다 (교사·학생이 같은 마이크를 쓰면 한국어용 하나 더). 학생 언어가 많을수록 연결이 많아집니다.
- **안 되면 자동으로 지금 방식으로** 바뀝니다: 어떤 말에 4초 안에 답이 없거나 번역이 빠지면 그 말은 지금 방식으로 다시 만들어 같은 자리에 씁니다.
  연결이 안 되거나 연달아 답이 없으면 "Live 모드가 안 돼서 … 지금까지 쓰던 방식으로" 알림이 뜨고, 그 수업은 지금 방식으로 이어 갑니다 (다음 수업에서 다시 해 봅니다).
- Live 모드에서는 **용어집**과 **Claude 번역**이 쓰이지 않습니다. 오른쪽의 **오늘 남은 무료 사용**에는 Live 사용량이 들어가지 않습니다 (지금 방식으로 처리한 말만 셉니다).
- 아직 시험 중이라, 선생님 PC 에서 지금 방식보다 정말 빠른지 **자막 지연 숫자**로 비교해 보시고 느리면 꺼 주세요.
- 학교 네트워크가 WebSocket 연결을 막으면 "Live 서버에 연결하지 못했습니다 (HTTP …)" 가 나옵니다. 이때는 Live 모드를 끄고 쓰세요.

## 6. 학생 PC 링크 (선택)
1. 왼쪽 메뉴 **학생 PC 링크** → 켜기 → 나오는 주소를 **복사**
2. 학생 PC 의 Chrome/Edge 에서 주소를 열고 🌐 에서 자기 언어를 고릅니다. 여러 명이 동시에 볼 수 있습니다.
- 학생 PC 가 교사 PC 와 **같은 학교 네트워크**에 있어야 합니다. 처음 켤 때 **Windows 방화벽** 창이 뜨면 허용을 누르세요.
- 학교 네트워크가 PC 끼리 통신을 막아 두었으면 열리지 않을 수 있습니다 (정보 담당 선생님께 문의).
- 링크를 켤 때마다 주소가 바뀝니다. 지난 주소로는 들어올 수 없습니다.
- ⚠️ Gemini API 약관은 **만 18세 미만이 이용하는 서비스**에 쓰는 것을 금지합니다. 학생이 미성년자라면 이 기능은 켜지 않는 것을 권장합니다.

## 7. Claude 번역 (선택, 유료)
1. [Claude 플랫폼](https://platform.claude.com/)에서 API 키를 만들고 결제를 등록합니다.
2. **API 키** → Claude 칸에 저장 → 연결 테스트
3. **속도·무료 사용량 → 번역 엔진** → Claude 선택 → 모델 선택
   - Opus 5.5(가장 정확, 월 약 11만 원) · Sonnet 5.5(월 약 6만 원) · Haiku 5.5(월 약 3천 원) — 하루 4교시 기준 대략치
- 받아쓰기는 계속 Gemini(무료)가 하고, 번역만 Claude 가 합니다. 받아쓰기는 Claude 를 기다리지 않고 먼저 보입니다.
- 속도가 중요하면 Haiku 5.5 가 가장 빠릅니다.

## 8. AI 허브 데이터 찾기 (선택, 무료)
[AI 허브](https://aihub.or.kr)에 있는 번역·통번역 데이터셋을 프로그램 안에서 찾아봅니다. 수업 자막 기능과는 따로 동작하며, 키가 없어도 자막은 그대로 됩니다.
1. AI 허브에 로그인 → [API 안내 페이지](https://aihub.or.kr/devsport/apishell/list.do?currMenu=403&topMenu=100)에서 **API 키 발급**
2. 프로그램 **API 키** → AI 허브 칸에 붙여넣기 → **저장** → **연결 테스트** ("'번역' 관련 데이터셋이 ○개 있어요"가 나오면 성공)
3. 왼쪽 메뉴 **AI 허브 데이터** → 학급 언어 버튼(예: **러시아어**)을 누르거나 직접 검색
   - AI 허브는 검색어가 그대로 들어간 데이터만 찾습니다. "러시아어 번역"보다 **"러시아어"** 처럼 짧게 찾으면 더 많이 나옵니다.
   - 학급 언어 이름으로 나오지 않으면 **다국어 통번역**도 눌러 보세요 (여러 언어를 묶은 데이터).
4. 데이터셋을 누르면 오른쪽에 소개, **메타데이터 구조표**(구축량·라벨링 형식), **파일 목록**(파일 수·크기)이 나옵니다. **AI 허브에서 열기·이용 신청** 으로 AI 허브 페이지에서 이용 신청을 합니다.
   - 예: 「다국어 일상대화 실시간 통번역 데이터」(71686)는 한국어·스페인어·프랑스어·러시아어 일상대화 음성과 전사·번역 json 입니다.
- 프로그램은 데이터셋 **설명(메타데이터)만** 가져옵니다. 데이터 파일을 내려받거나 다른 곳으로 보내지 않습니다.
- AI 허브 데이터는 대부분 **재배포가 금지**되어 있습니다. 내려받은 데이터는 선생님 PC 안에서만 쓰고, 학생·다른 선생님에게 파일을 나눠 주지 마세요.

## 9. 개인정보와 동의
- 수업 중 말소리는 Google Gemini 로 전송됩니다. **무료 등급**에서는 Google 이 보낸 내용을 제품 개선에 쓸 수 있고 사람이 검토할 수 있습니다.
- 이 프로그램은 **음성과 자막을 파일로 저장하지 않습니다.** 화면의 자막 기록은 프로그램을 닫으면 사라집니다. (저장되는 것: 설정, 오늘 사용량, 암호화된 키)
- 가정통신문 안내 예시:
  > 우리 반은 외국어를 쓰는 학생의 수업 이해를 돕기 위해 실시간 통역 자막 프로그램을 사용합니다.
  > 수업 중 말소리가 Google Gemini(무료 서비스)로 전송되어 글자로 바뀌고 번역되며,
  > Google 이 서비스 개선을 위해 이 내용을 활용할 수 있습니다. 프로그램은 음성이나 자막을 따로 저장하지 않습니다.

## 10. 문제 해결
| 증상 | 해결 |
| --- | --- |
| 마이크를 열지 못했다고 나옴 | Windows **설정 → 개인 정보 → 마이크** 에서 "데스크톱 앱이 마이크에 접근하도록 허용" 켜기, **마이크** 메뉴에서 다시 선택 |
| 마이크 막대가 움직이지 않음 | **마이크 → 마이크 목록 새로고침** 후 맞는 장치 선택 |
| "키가 올바르지 않습니다" | AI Studio 에서 키를 새로 만들어 다시 저장 |
| "이 키로 쓸 수 있는 Gemini 모델이 없습니다" | **API 키 → 연결 테스트**를 눌러 모델 목록을 다시 받기 |
| "모든 모델이 분당 요청 한도에 걸려…" 가 자주 뜸 | **속도·무료 사용량 → 자막 속도**를 '보통'으로 |
| 무료 사용량이 너무 빨리 줄어듦 | 자막 속도를 '보통'·'절약'으로, 또는 **느리면 다른 모델로 한 번 더 보내기** 끄기 |
| 자막이 10초 넘게 늦음 | 무료 서버가 붐비는 때입니다. 잠시 뒤 나아지며, 계속되면 '번역'을 **빠르고 넉넉하게**로 |
| 자막이 PPT·영상 위에 안 보임 | `Ctrl`+`Alt`+`H` 두 번 눌러 다시 띄우기 |
| 자막 창이 안 보이는 곳으로 갔음 | **자막 창 → 처음 위치로** |
| 도구 막대의 [이동]·모서리나 위치 버튼을 눌러도 자막 창이 안 움직임 | v0.6.2 에서 고쳤습니다 (왼쪽 메뉴 아래 버전 확인). 그래도 안 되면 **자막 창 → 문제 보고용 정보 복사** 를 눌러 복사된 내용을 보내 주세요. 그동안은 `Ctrl`+`Alt`+`M` 으로 옮길 수 있습니다 |
| 두 번째 모니터(프로젝터·TV)에서 자막 창이 엉뚱한 곳에 가거나 크기가 맞지 않음 | 노트북과 프로젝터의 Windows 배율이 다를 때 생기던 문제로 v0.6.1 에서 고쳤습니다. **자막 창 → 어느 화면에?** 에서 그 화면을 다시 누르세요 |
| AI 허브 "API 키가 없습니다" / "유효하지 않은 API 키" | AI 허브 API 안내 페이지에서 키를 다시 확인해 **API 키 → AI 허브** 에 저장 |
| AI 허브 검색 결과가 없음 | "러시아어", "통번역" 처럼 짧은 말로 다시 검색. 우즈베크어·몽골어처럼 아직 단독 데이터가 없는 언어도 있습니다 |
| AI 허브 "잘못된 접근입니다" | 프로그램을 최신판(v0.4.1 이상)으로 바꿔 주세요 |
| 학생 링크가 안 열림 | 같은 네트워크인지, 방화벽 허용했는지 확인. **학생 PC 링크**에서 포트를 바꿔 보기 |
| "Live 모드가 안 돼서 … 지금까지 쓰던 방식으로" | 알림 끝의 이유를 확인하세요. "쓸 수 없는 Live 모델" → **API 키 → 연결 테스트** 후 다른 Live 모델 고르기. "HTTP …" → 학교 네트워크가 막는 경우라 Live 모드 끄기. "한도" → 그날은 Live 모드 끄기 |
| Live 모드에서 자막이 오히려 늦음 | **속도·무료 사용량 → Live 모드** 를 끄면 지금 방식으로 돌아갑니다 |
